# Mary Poppins — лендинг детского сада

Next.js 15 · TypeScript · Tailwind CSS 4 · Lucide React

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production-сборка
```

## Фотографии (`public/images`)

Изображения подхватываются автоматически при сборке:

| Файл | Где используется |
|------|------------------|
| `logo.png` / `logo.svg` / … | Логотип в шапке и на главном экране (если файла нет — показывается разноцветное название) |
| `main-page.jpg` (или `main.*`, `hero.*`) | Главное фото |
| `about.jpg` | Фото в разделе «О садике» (необязательно; иначе берётся первое фото галереи) |
| остальные файлы | Галерея, по порядку имён (`image1`, `image2`, …) |

Форматы: jpg, jpeg, png, webp, gif, avif, svg.

## Настройки

Все контакты и ссылки — в `src/data/site.ts`:

- `DOCUMENTS_URL` — ссылка на папку Google Drive с документами (пока пустая, кнопка неактивна).
- `MAP` — точка детского сада по карточке организации в 2ГИС.

## Деплой на Vercel

Импортируйте репозиторий в Vercel — настройки по умолчанию подходят.
Для корректных canonical / Open Graph ссылок можно задать переменную `NEXT_PUBLIC_SITE_URL`
(например, `https://marypoppins.kz`); иначе используется домен проекта Vercel.
